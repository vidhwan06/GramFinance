# GramFinance — Digital Financial Safety & Literacy Platform

> **Understand. Verify. Decide Safely.**

A multilingual, voice-friendly platform that helps rural households understand financial products, identify digital-payment fraud, evaluate basic borrowing costs, and discover relevant official financial-support resources.

---

## 🛠️ Technology Stack
- **Frontend**: Next.js 15, React 19, TypeScript, Tailwind CSS
- **Backend**: Next.js Serverless API Routes
- **Database**: Supabase (PostgreSQL)
- **AI Integration**: Google Gemini API (Server-side proxy)
- **OCR Engine**: Tesseract.js

---

## 🚀 Getting Started

### 1. Environment Setup
Copy `.env.example` to `.env.local`:
```bash
cp .env.example .env.local
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
